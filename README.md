# คลิปอนิเมชั่น 3D สนามบาส (5 วินาที)

ฉาก 3D ที่เขียนด้วย JavaScript + [Three.js](https://threejs.org) เลียนแบบสไตล์คลิป "theoddtilt":
สนามบาสหลังบ้าน รั้วไม้ แป้นบาส ลังไม้ ที่สูบลม ชายเสื้อเชิ้ตน้ำเงินกับชายเสื้อยืดขาว

- **0.0–2.3 วิ** ช็อตใกล้: ชายเสื้อน้ำเงินปล่อย "ลูกหิน" ลงพื้น → ไม่เด้ง เศษหินกระจาย กล้องสั่น (ซับ: *Stone balls, don't bounce...*)
- **2.3–5.0 วิ** มุมกว้าง: ชายเสื้อขาวชี้ ชายเสื้อน้ำเงินเลี้ยงลูกบาสยางสีส้ม (ซับ: *So rubber! Clever!*)

ทุกอย่าง (ตัวละคร, texture, ฉาก) สร้างจากโค้ดล้วน ไม่มีไฟล์โมเดลภายนอก

## ไฟล์
- `src/scene.js` — ฉาก ตัวละคร (โครงกระดูกแบบลำดับชั้น) และ timeline อนิเมชั่น
- `src/index.html` — หน้า 720×1280 (แนวตั้ง 9:16) + ซับไตเติล
- `render.mjs` — เรนเดอร์ทีละเฟรมด้วย Chromium (Playwright) แล้วรวมเป็น MP4 ด้วย ffmpeg
- `output/clip.mp4` — คลิปตัวอย่างที่เรนเดอร์แล้ว (5 วิ, 30 fps)

## วิธีใช้
```bash
npm install
npm run render     # ได้ output/clip.mp4 (ต้องมี playwright + ffmpeg)
npm run preview    # เปิดดูแบบ real-time ในเบราว์เซอร์
```
